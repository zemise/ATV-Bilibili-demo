# 隐私与推送

公共仓库使用通用 Bundle ID 默认值，不保存个人签名团队。实际配置位于忽略的 `config/Local.xcconfig` 和 `config/ExportOptions.local.plist`，照片本地备份位于忽略的 `config/private-assets/`。个人 Top Shelf 图片应通过应用内上传，不替换仓库默认素材后提交。

推送前执行 `make privacy-check`，提交后可执行 `python3 scripts/check-privacy.py --ref HEAD` 检查实际提交树。检查覆盖常见密钥、会话 Cookie、个人绝对路径、签名团队和本机文件；只输出文件及问题类型，不输出匹配值。它不能识别所有凭据、照片人物或 EXIF 内容，新增图片、日志和配置仍须人工审查。不提交登录数据、播放日志、签名证书、描述文件或个人照片。

2026-10-31 清理将个人照片替换为上游默认 Top Shelf 图片，并从当前索引移除 `.DS_Store`。本机原图保留为忽略的备份。

**历史范围：** 按维护者确认，清理 fork 的 `main` 历史中的个人照片、Finder 元数据及个人签名标识，并将 fork 提交中的维护者邮箱替换为 GitHub noreply 地址；上游原始提交和作者署名保持不变。远端当前只有 `main` 分支，无需更新远端标签。重写前的仓库与工作区已备份在本机仓库外，不上传备份。使用带旧提交校验的 `--force-with-lease` 更新远端。其他协作者需基于新历史重新同步，避免把旧提交合回。

历史重写只能移除公开分支的可达引用，不能保证清除 GitHub 的旧提交缓存、其他 fork、克隆或历史 Actions 产物；如需消除这些副本，应按相应托管平台流程进一步处理。本机 stash、Codex 检查点和私有备份不属于推送范围，仍可包含清理前数据。
